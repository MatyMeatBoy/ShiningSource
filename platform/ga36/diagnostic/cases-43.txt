# apply the four script changes below. tools/ga36_diag_report.py reads the result (case names keep v1's patterns:
# cap-headless, cap-render-W, cap-nopic-*, cap-noshow-V, cap-show-V, hash-*, play-paced-*).
#
# Script changes
# 1. The child gets everything explicitly: export game rom DIAG_ENVSH before re-invoking "$self" --child, and the
#    child also recomputes game from DIAG_GAME if empty and exits 121 with "game vacio" on stderr if still empty.
#    (v1 bug: $game empty in the child -> exec /libarmhf/ld-linux-armhf.so.3 not found, exit 127 in 1.2 s, run lost.)
# 2. Pre-flight case 00-preflight before anything else: headless SS_FRAMES=60 and sdl SS_QUIT=60 SS_PICTURE=2.
#    If either exits != 0, or the headless one prints no "frame    60  hash" line: write
#    "DIAGNOSTICO ABORTADO: el juego no arranca (salida N): <last stderr line>" to /dev/tty0 and to status.txt
#    ("ABORT preflight N"), keep the census, sleep 20 s so it can be read, END 1. No other case runs.
# 3. Watchdog by wall clock: each case records t0=$(up) and is killed when up - t0 > budget (TERM, 5 s, KILL),
#    polled every second; the global deadline also uses /proc/uptime (DIAG_DEADLINE=840 s after the census).
#    No counting of loop rounds (a busy board makes `sleep 1` rounds longer than a second).
# 4. Every case's env is written in full (no implicit defaults): SS_SKIP SS_NET SS_FRAMELOG SS_CANVAS SS_VIEW
#    SS_VIEW_H SS_FB_VIEW SDL_AUDIO_DRIVER and the case's own; env.txt is the exact list. Crash cases keep
#    stderr, dmesg tail and any crash log the runtime writes (copied as crash-*.txt).
#
