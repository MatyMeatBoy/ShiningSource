# Shining Soul II

| | |
|---|---|
| ROM | Europe, `AU2P`, SHA-1 `aa1288be9257337abdfe3034898cf6c7aa778fbc` (bring your own) |
| Decompilation | `decomp/` (submodule of MatyMeatBoy/SS2Decomp) |
| Port files | `port/` |

`port/modules.json`: decomp modules that the runtime replaces, with the reason.
`port/hoist.json`: functions used before their file declares them (generated by
`tools/build.py fix`). `port/patches.json`: exact source replacements, each with
its reason; a patch that stops applying fails the build instead of being skipped.

Anything found here that is really a defect of the decompilation (a wrong
prototype, a declaration in the wrong order) should be fixed in SS2Decomp, with
the ROM still matching, and then removed from this folder.
