# RetroAchievements snapshot

Source: https://retroachievements.org/game/7095
Downloaded on 2026-11-17 through the official achievementsets API for the supported European ROM (RA hash `49aa688745111aaa51076a345f8f18c3`).

The response is preserved unchanged: 52 published game achievements, 454 points, two unofficial entries, and the server's unknown-client warning. Only published game achievements are evaluated locally. The warning is not a game achievement; hardcore support is not approved. Definitions, titles, descriptions and badge art belong to their respective RetroAchievements authors. The API response contains no credentials or player progress.

These files provide an initial offline catalog and badges. Signing in can refresh the catalog through the official client integration. Local and Rebel progress are kept separately and are never imported into an account.

Windows release archives place badge images in `achievements/badges/`. The launcher and the game move loose badges from older installations into that folder on startup. Identical duplicates are removed and conflicting older images are preserved in `achievements/badges/legacy/`.
